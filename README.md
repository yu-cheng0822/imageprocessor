# ImageProcessor 影像處理器

這是一個基於 Qt6 的影像處理應用程式，提供多種影像處理和編輯功能。

## 功能特點

### 基本功能
- 開啟影像檔案（支援 BMP、PNG、JPEG 格式）
- 影像放大/縮小
- 幾何轉換（鏡射、旋轉）
- 滑鼠位置追蹤與灰階值顯示

### 區域放大與編輯功能（新增）
1. **區域選取放大**
   - 在主視窗中，使用滑鼠左鍵拖曳選取想要放大的區域
   - 釋放滑鼠後，系統會彈出對話框詢問放大倍率（1.0 - 10.0 倍）
   - 輸入倍率後，會開啟新視窗顯示放大的影像

2. **放大視窗功能**
   - **畫筆繪圖**：可以在放大的影像上進行繪圖標註
     - 調整畫筆粗細（1-20 像素）
     - 選擇畫筆顏色
     - 清除繪圖內容
   - **另存新檔**：可將放大後的影像（含繪圖標註）儲存為新檔案

## 編譯方式

### 系統需求
- Qt 6.x 或更高版本
- C++17 編譯器
- qmake 或 CMake

### 使用 qmake 編譯
```bash
qmake6 imageprocessor.pro
make
```

### 執行程式
```bash
./imageprocessor
```

## 使用說明

1. **開啟影像**
   - 點擊「檔案」→「開啟檔案」或使用工具列的開啟按鈕
   - 選擇想要處理的影像檔案

2. **區域放大**
   - 在影像上按住滑鼠左鍵並拖曳，選取想要放大的區域
   - 釋放滑鼠後，輸入放大倍率
   - 在新開啟的放大視窗中進行編輯

3. **繪圖編輯**
   - 在放大視窗中，可使用畫筆工具在影像上繪圖
   - 調整畫筆粗細和顏色
   - 可隨時清除繪圖內容

4. **儲存結果**
   - 點擊「另存新檔」按鈕
   - 選擇儲存路徑和檔案格式

## 專案結構

```
imageprocessor/
├── main.cpp                # 程式進入點
├── imageprocessor.h/cpp    # 主視窗類別（包含區域選取功能）
├── zoomwindow.h/cpp        # 放大視窗類別（包含繪圖功能）
├── imagetransform.h/cpp    # 幾何轉換視窗類別
├── mainwindow.h/cpp        # 基本視窗類別
└── imageprocessor.pro      # Qt 專案檔
```
